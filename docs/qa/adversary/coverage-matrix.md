**Unanswerable** — a read against a table that is empty on dev. The actor sees
nothing, but so does service-role, so the cell proves nothing. Excluded rather
than counted as a pass.

**Characterized** — the cell depends on something no static rule can predict: a
visibility dial, a department match, a status, an owner comparison. Recorded
and diffable, never asserted. Claiming to predict them would manufacture
failures and train everyone to ignore this file.

A denied SELECT does not error in PostgREST — it returns an empty set — so read
visibility is measured against what service-role can see, not against the
absence of an error. The first version of this file got that wrong and reported
1,116 cells of nothing (see finding K1).
